# Руководство пользователя

Для первой самостоятельной проверки используйте [полный пошаговый сценарий](MANUAL_CHECK.md):
он включает команды сборки, ожидаемые результаты и экспорт собственного чата из Telegram.

## Первый запуск

Откройте корневую папку TelegramChatNavigator в VS Code. В терминале выполните
`dotnet run --project src/TelegramChatNavigator.Desktop`.
Дождитесь заголовка «Поход выходного дня» и подписи «14 сообщений · 3 авторов».
Слева — поиск и переход по датам, в центре — лента, справа — подробности выбранного сообщения.
Первая строка выбрана сразу. Весь исходный текст доступен справа, даже если в ленте он сокращён по высоте.

Автономный `.app` открывается двойным нажатием и содержит те же демоданные.
Для остановки закройте окно или нажмите Cmd+Q. Файл работы сохраняется вручную.

## Основной сценарий с ожидаемыми результатами

1. В поле поиска введите `маршрут`, нажмите **Найти** или Enter при фокусе в этом поле.
   В центре должны остаться №4, №5, №12, №14; подпись — «1–4 из 4».
2. В «Тип сообщения» выберите **Ссылки** и снова нажмите **Найти**.
   Получится два сообщения — №4 и №12. Фильтры применяются явно кнопкой, не сразу после выбора.
3. Выберите №4. Справа появятся полный текст и адрес `https://www.mchs.gov.ru/`.
   **Открыть в браузере** передаёт выбранную HTTP/HTTPS-ссылку системному браузеру.
   Строка «рекомендации МЧС» в исходном JSON была текстовой гиперссылкой: её адрес не теряется.
4. Нажмите **Контекст**. Фильтры очистятся, все 14 сообщений вернутся, №4 останется выбранным.
5. Выберите тип **Фотографии**, нажмите **Найти**. Появятся №3 и №9.
   При выборе №3 справа виден рисунок озера. Для №9 вы получите сообщение, что файл не включён в экспорт.
   Это намеренный тест: отсутствующее вложение не мешает просмотру чата.
6. Выберите **Опросы**, очистите строку поиска, нажмите **Найти**. Останется №6.
   Справа показаны вопрос, два варианта (2 и 1 голос) и всего 3 участника.
   Это снимок результатов при экспорте, голосовать в нём нельзя.
7. Выберите **Аудио и голосовые**, нажмите **Найти**, затем **Открыть вложение**.
   На Mac откроется окно навигатора со встроенным системным AVKit; нажмите **▶ Воспроизвести** под областью просмотра; там же доступны пауза и шкала. На Windows/Linux используется приложение по умолчанию. Громкость не меняется навигатором.
   Повторите с категорией **Видео** — двухсекундный MP4. После проверки закройте окно проигрывателя. Если AVKit не поддерживает кодек, доступна кнопка «Открыть внешним приложением». На Windows/Linux нужен назначенный системный проигрыватель.
8. Нажмите **Сброс**. В поле быстрого перехода введите `2026-10-01` и нажмите **К дате**.
   Выбран №11. «К месяцу» для `2026-10` даёт тот же результат.
   Переход снимает фильтры, чтобы найти дату во всём чате. Если день пуст, выбирается ближайший следующий;
   если дата позже последнего сообщения, появится понятная подпись.
9. В списке авторов выберите **Борис**, нажмите **Найти**. Останутся его сообщения.
   Это список авторов, встречающихся в экспорте; Telegram не сохраняет здесь полный список молчащих участников.
10. Сбросьте фильтры, выберите №10, нажмите **К ответу**. Выбран №6, на который отвечала Алина.
    Если исходное сообщение не попало в экспорт, интерфейс сообщает об этом.

## Избранное и порядок сообщений

Выберите сообщение и нажмите **☆ В избранное** справа. Повторное нажатие **★ Убрать из избранного** снимает отметку.
Слева показано общее количество избранных сообщений. Включите **Только избранное** и нажмите **Найти**.
Этот фильтр сочетается с автором, периодом, типом и текстом; **Сначала новые** меняет порядок результата.
В демо отметьте №4 и №12: только избранное + сначала новые даёт №12, затем №4.
После удаления последнего избранного результата лента будет пустой — снимите флажок или нажмите **Сброс**.

**Сохранить** записывает избранное, порядок и фильтры в `.tgnav.json`. После перезапуска выберите **Загрузить**.
Повторный импорт/«Демо» начинает новую работу без отметок; исходный экспорт Telegram не изменяется.
Переход к дате/месяцу и **Контекст** снимают фильтры и возвращают хронологический порядок, сохраняя сами отметки.

## Окно фотографий

Выберите №3 и нажмите **Открыть вложение**. В отдельном окне приложения доступны **Предыдущая/Следующая**,
масштаб **+/−**, **Вписать** и прокрутка увеличенного изображения. Стрелки ←/→ меняют фото, 0 вписывает его в окно,
Esc закрывает просмотр. Навигация проходит по всем фотографиям архива, независимо от фильтра основной ленты.
Отсутствующее фото №9 показывает объяснение; можно вернуться к №3. Это окно и миниатюра реализованы в приложении.

## Период, страницы и длинный текст

Для периода с 2 сентября по 2 сентября введите в обе строки `2026-09-02` и нажмите **Найти**.
Это два сообщения: №4 и №5. Время внутри выбранного дня не исключает сообщения.
Пустая граница периода означает отсутствие ограничения с этой стороны.
Неверная дата или обратный период дают ошибку, а прежние результаты остаются на экране.

При большом чате **Назад/Далее** переключают страницы по 50 сообщений. Внутри страницы есть прокрутка.
№13 в демо содержит длинный текст: выберите его и прокрутите правую панель.
Окно допускает изменение размера до 1060×680; панели прокручиваются отдельно, поля оставляют место для scrollbar.
Tab/Shift+Tab переводят фокус, стрелки меняют выбор в списках.

## Сохранение и продолжение

1. Установите поиск `маршрут`, тип «Ссылки» и нажмите **Найти**. Выберите №12.
2. **Сохранить** → укажите `chat.tgnav.json` в удобной папке. Дождитесь строки «Состояние сохранено».
   Отмена системного диалога не изменяет работу. Перезапись подтверждается стандартным диалогом macOS.
3. Нажмите **Демо** или перезапустите приложение, чтобы получить исходный чат без фильтра.
4. **Загрузить** → выберите `chat.tgnav.json`. Вернутся запрос, категория и выбор №12.
5. Для переноса скопируйте состояние вместе со всей папкой экспорта, сохранив расположение относительно файла состояния.
   Если медиа переместились отдельно, используйте **Папка медиа** и снова сохраните состояние.
6. Для проверки повреждённого файла сделайте копию состояния и нарушьте в ней JSON. При загрузке будет ошибка;
   исходная работа на экране останется. Свою единственную копию не портите.

На Windows при разных дисках для состояния и медиа используется абсолютный путь: относительный между дисками невозможен. При переносе такого проекта выберите «Папка медиа» заново.

Файл состояния включает все тексты чата, а не только найденные строки. Медиафайлы в JSON не встраиваются.
CSV кнопкой **Экспорт CSV** содержит текущие результаты поиска; он не позволяет восстановить состояние.
В состоянии нет темы и размера текста: они сохраняются отдельно кнопкой **Сохранить настройки**.
System/Light/Dark означает системную, светлую и тёмную темы. Размер текста: 12, 15, 18, 21.

## Реальный экспорт и HTML

Распакуйте архив преподавателя заранее. Выберите папку с `result.json` или `messages.html`.
Все `messages2.html`, `messages3.html` и далее должны лежать рядом с первой страницей.
HTML читается как данные: JavaScript не запускается, внешние ресурсы не скачиваются.
Для отдельной проверки HTML откройте `examples/html-demo`: три сообщения с двух страниц.
При наличии JSON и HTML папка по умолчанию открывает JSON. Явно выбрать HTML можно параметром
`--open examples/html-demo/messages.html` или CLI с путём к HTML-файлу.

## Горячие клавиши и справка

| Клавиши Mac | Действие |
|---|---|
| F1 или Fn+F1 | Справка по управлению и CLI |
| Cmd+? | Справка без функциональных клавиш |
| Cmd+O | Выбрать папку экспорта |
| Cmd+S | Сохранить состояние |
| Cmd+L | Загрузить состояние |
| Cmd+F | Перевести фокус в поиск |
| Enter в поиске | Применить фильтры |
| Tab / Shift+Tab | Следующий / предыдущий элемент |
| Стрелки | Выбор в ленте и списках |

На Linux/Windows для O/S/L/F используется Ctrl. На macOS аудио/видео показывает встроенный AVKit; на Windows — приложение по умолчанию, на Linux — xdg-open в графическом сеансе.
Кнопка «Справка» всегда доступна. Перенастраивать верхний ряд клавиатуры Mac не требуется.
