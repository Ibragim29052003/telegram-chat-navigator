# Пошаговая самостоятельная проверка

Этот сценарий рассчитан на Mac и текущую версию 1.1.0. Сначала проверьте демо с известными ответами,
затем небольшой собственный экспорт. Ориентир по времени: 25–40 минут плюс скачивание экспорта Telegram.
Отмечайте результат только после того, как лично выполнили соответствующее действие.

## 1. Откройте правильную папку

В VS Code выберите File → Open Folder и откройте папку TelegramChatNavigator,
в которой лежат TelegramChatNavigator.sln, README.md, src, tests и examples.
Откройте Terminal → New Terminal. Терминал должен находиться в корне проекта.
Для перехода из другого каталога используйте команду ниже, заменив пример пути реальным:

```sh
cd "/путь/к/TelegramChatNavigator"
```

## 2. Проверьте сборку и тесты

Последовательно выполните:

```sh
dotnet --version
dotnet restore --locked-mode
dotnet build -c Release --no-restore
dotnet test -c Release --no-build --no-restore
```

Ожидается SDK 10.0.x (при подготовке был 10.0.400), успешные restore/build и **55 пройденных тестов**.
Первый restore может скачивать пакеты из NuGet. Если получена ошибка, сохраните её текст и команду;
переустанавливать работающий SDK заранее не нужно.

## 3. Запустите окно

```sh
dotnet run --project src/TelegramChatNavigator.Desktop -c Release --no-build --no-restore
```

Ожидается чат **«Поход выходного дня»**, **14 сообщений**, **3 автора**, выбранное первое сообщение.
Уменьшите и увеличьте окно: текст не должен накладываться на поля и полосы прокрутки.
Лента и правая панель прокручиваются отдельно. Минимальный размер окна — 1060×680.

Оконная программа занимает этот терминал до закрытия. Для команд CLI откройте второй терминал VS Code
или сначала закройте окно. Закрытие: кнопка окна/Cmd+Q; остановка из терминала: Ctrl+C.

Готовую сборку можно проверить отдельно: в Finder откройте artifacts/TelegramChatNavigator.app.
Для проверки одного экземпляра используйте один способ запуска за раз.

## Избранное и окна просмотра

1. Нажмите **Сброс**, выберите №4, затем **☆ В избранное**. Отметьте также №12.
2. Включите **Только избранное**, выберите **Сначала новые**, нажмите **Найти**. Ожидаются №12 и №4 в этом порядке.
3. Добавьте автора Борис и нажмите **Найти**: останется №12. Сохраните состояние, откройте демо, загрузите состояние: вернутся отметки, фильтры и выбор.
4. Уберите №12 из избранного: при этом фильтре результатов больше нет. Нажмите **Сброс** — все 14 сообщений доступны, №4 остаётся избранным.
5. Выберите фото №3 → **Открыть вложение**. Проверьте +/−, **Вписать**, стрелки. Следующее фото №9 отсутствует намеренно; возврат к №3 должен работать. Esc закрывает окно.
6. На Mac откройте №7 и №8. Проигрыватель находится в окне навигатора: нажмите ▶, проверьте движение шкалы, паузу и закрытие окна. QuickTime для обычного просмотра не запускается.
7. На Windows/Linux аудио и видео передаются внешнему системному проигрывателю. Встраивание AVKit относится только к Mac.

## 4. Проверьте поиск и ссылки

| Действие | Ожидаемый результат |
|---|---|
| Нажмите «Демо», введите `маршрут`, нажмите «Найти» | 4 сообщения: №4, №5, №12, №14 |
| Оставьте запрос, выберите «Ссылки», нажмите «Найти» | 2 сообщения: №4 и №12 |
| Выберите №4 | Справа полный текст и адрес https://www.mchs.gov.ru/ |
| Нажмите «Открыть в браузере» | Открывается выбранная ссылка в браузере |
| Нажмите «Контекст» | Вернулись все 14 сообщений, выбранное №4 сохранено |

Фильтр применяется кнопкой «Найти», Enter работает при фокусе в поле поиска.
Поиск ищет подстроку без учёта регистра: `МАРШРУТ` совпадёт с `маршрут`, а разные словоформы автоматически не подбираются.
Перед каждой следующей независимой проверкой нажимайте **«Сброс»**, чтобы убрать прежние условия.

## 5. Проверьте вложения и опрос

| После «Сброс» выберите категорию и нажмите «Найти» | Ожидаемый результат |
|---|---|
| «Фотографии» | №3 и №9. У №3 внутри окна рисунок озера; у №9 понятное сообщение об отсутствующем файле |
| «Опросы» | №6: «Когда идём в поход?», суббота — 2 голоса, воскресенье — 1, всего 3 |
| «Аудио и голосовые» → №7 → «Открыть вложение» | В окне навигатора встроенный AVKit открывает signal.wav. Play воспроизводит сигнал длительностью 1 секунду |
| «Видео» → №8 → «Открыть вложение» | В окне навигатора встроенный AVKit открывает demo.mp4. После Play шкала проходит 2 секунды |
| «Файлы» → №5 → «Открыть вложение» | Системный текстовый редактор открывает файл маршрута |

Видео специально состоит из неподвижного рисунка и не содержит звука. Его воспроизведение проверяйте
по шкале времени; звук проверяется отдельным WAV. После проверки закройте окна просмотрщиков.
Фото №9 намеренно отсутствует в демо: это проверка обработки неполного экспорта, а не поломка программы.
Опрос показывает сохранённые результаты; голосовать в нём нельзя.

## 6. Проверьте даты, авторов и ответы

Каждую строку начинайте со «Сброс».

| Действие | Ожидаемый результат |
|---|---|
| В быстром переходе введите `2026-10-01`, нажмите «К дате» | Выбрано №11 |
| Выберите месяц `2026-10`, нажмите «К месяцу» | Выбрано №11 |
| В обе границы периода введите `2026-09-02`, нажмите «Найти» | Только №4 и №5 |
| Выберите автора Борис, нажмите «Найти» | №3, №5, №8, №12 |
| Перейдите к дате `2026-09-05`, выберите №10, нажмите «К ответу» | Выбрано исходное сообщение №6 |
| Перейдите к дате `2026-10-03`, выберите №13 | Длинный текст полностью читается и выделяется в правой панели |

Даты вводятся как yyyy-MM-dd. Переход по дате/месяцу снимает фильтры.
Если в указанный день сообщений нет, выбирается первое следующее сообщение.
Число рядом с именем автора — количество его сообщений. 14 записей демо включают одно служебное событие.

## 7. Проверьте продолжение работы после закрытия

Создайте отдельную папку для личных результатов, вне репозитория:

```sh
mkdir -p "$HOME/Documents/TelegramNavigatorCheck"
```

1. В окне нажмите «Сброс», введите `маршрут`, выберите «Ссылки», нажмите «Найти».
2. Выберите **№12** — важно проверить сохранение не только первой строки.
3. Нажмите «Сохранить». Сохраните в созданную папку файл **demo-session.tgnav.json**.
4. Дождитесь сообщения «Состояние сохранено».
5. Закройте приложение, запустите его той же командой снова.
6. Нажмите «Загрузить», выберите demo-session.tgnav.json.
7. Проверьте: запрос `маршрут`, категория «Ссылки», два результата и выбранное **№12** восстановились.
8. Нажмите «Сброс»: должны вернуться все 14 сообщений. Сохраняется весь чат, а не только две найденные строки.

**result.json** — исходный экспорт Telegram; **demo-session.tgnav.json** — состояние нашего приложения.
Это разные форматы. Файл состояния не включает само видео/аудио/фото: их папка должна оставаться доступной.

## 8. Проверьте CSV и настройки

1. Снова примените `маршрут` + «Ссылки» и нажмите «Экспорт CSV».
2. Сохраните demo-results.csv в TelegramNavigatorCheck.
3. Откройте CSV в VS Code. Первая строка — названия колонок, далее два сообщения с ID 4 и 12.
   Кавычки и запятые — нормальная часть формата CSV.
4. Выберите тему Dark/Light и размер текста 18, нажмите «Сохранить настройки».
5. Перезапустите окно: тема и размер должны сохраниться. Настройки и состояние чата сохраняются отдельно.
6. Проверьте «Справка», F1/Fn+F1, Cmd+F, Enter в поиске, Tab/Shift+Tab.

## 9. Проверьте ошибки и отмену

- При непустом результате поиска нажмите «Сохранить» и отмените системный диалог. Работа должна остаться прежней.
- В границу периода введите `не дата`, нажмите «Найти». Должно появиться объяснение формата; прежние результаты остаются.
- Укажите начало периода позже конца. Ожидается сообщение об ошибке, без закрытия окна.
- Откройте пустую папку вместо экспорта. Ожидается сообщение об отсутствии result.json/messages.html, прежний чат сохраняется.
- Дополнительно сделайте **копию** состояния, удалите в копии закрывающую фигурную скобку и попробуйте загрузить её.
  Ожидается ошибка повреждённого JSON; текущий чат не заменяется. Единственную сохранённую копию не редактируйте.

## 10. Экспортируйте собственный чат

Используйте **Telegram Desktop**. Официальная инструкция Telegram описывает экспорт одного чата
через меню чата «…» → **Export chat history / Экспорт истории чата**:
[Telegram: Chat Export Tool](https://telegram.org/blog/export-and-more).

1. Откройте небольшой личный чат или группу, где есть знакомые вам сообщения и несколько вложений.
2. В меню этого чата выберите экспорт истории. Экспорт аккаунта целиком через настройки для нашего импорта не подходит.
3. Для первой проверки ограничьте период несколькими днями или неделями.
4. Выберите **Machine-readable JSON / JSON**.
5. Включите фотографии, видео, голосовые/аудио и файлы, которые хотите проверить.
6. Лимит размера вложений должен позволять скачать выбранные файлы. Исключённое при экспорте медиа навигатор восстановить не сможет.
7. Выберите папку вне проекта, например внутри Documents/TelegramNavigatorCheck, и дождитесь завершения экспорта.
8. В Finder найдите **конечную папку, внутри которой лежит result.json**, и сохраните её со всеми подпапками медиа.

Если нужного пункта нет, проверьте, что используется [Telegram Desktop](https://desktop.telegram.org/):
в официальном списке есть отдельные клиенты PC/Mac/Linux и macOS. Название меню может отличаться по языку/версии.
Если Telegram просит подтверждение экспорта, следуйте показанным им указаниям.

Пример расположения файлов:

```text
TelegramNavigatorCheck/
  MyChatExport/
    result.json
    photos/
    video_files/
    ...
  my-chat.tgnav.json
  my-results.csv
```

Названия подпапок зависят от содержимого экспорта. Не переносите один result.json отдельно от медиа.
Собственный экспорт и состояние содержат вашу переписку: храните их вне публичного репозитория.
Для работы навигатора не нужны токены Telegram или вход в аккаунт внутри нашей программы.

## 11. Проверьте собственный экспорт в окне

1. Нажмите **«Открыть экспорт»** и выберите папку, где непосредственно лежит result.json.
2. Проверьте название чата, несколько знакомых сообщений и их даты.
3. Найдите конкретную подстроку, которая точно есть в экспортированном периоде; сравните с Telegram.
4. Нажмите «Сброс», проверьте отдельно авторов и доступные категории медиа.
5. Откройте знакомые фото, короткое видео и аудио. Если такой категории в чате нет, пустой список — ожидаемый результат.
6. Перейдите к известной дате, затем проверьте диапазон дней.
7. Если сообщений больше 50, нажмите «Далее», затем «Назад». Должны меняться страницы, без потери сообщений внутри результата.
8. Сохраните **my-chat.tgnav.json**, перезапустите и восстановите запрос и выбранное сообщение.
9. Экспортируйте небольшой найденный результат в CSV и сравните его со списком в окне.

Опросы и ответы проверяйте, если они действительно есть в этом экспорте.
Авторы — участники, встречающиеся в сохранённых сообщениях; молчащих членов группы экспорт не восстанавливает.
Для JSON-файла установлен предел 128 МиБ и 200 000 сообщений. Для начала предпочтителен небольшой экспорт.
Импорт общего экспорта аккаунта, ZIP/7z без распаковки и произвольного JSON не поддерживается.

Дополнительно можно экспортировать тот же небольшой период в HTML в **другую папку** и открыть её.
Оставляйте messages.html, messages2.html и последующие страницы рядом.
Если JSON и HTML лежат вместе, выбор папки предпочитает JSON. Не смешивайте страницы разных чатов.

## 12. Проверьте CLI

В новом терминале перейдите в корневую папку проекта командой из шага 1.

```sh
dotnet run --project src/TelegramChatNavigator.Cli -- --help
dotnet run --project src/TelegramChatNavigator.Cli -- inspect examples/demo
dotnet run --project src/TelegramChatNavigator.Cli -- participants examples/demo
dotnet run --project src/TelegramChatNavigator.Cli -- search examples/demo --text маршрут --kind Link
```

Ожидаются справка; 14 сообщений и три автора; список Алины/Бориса/Веры; два результата №4 и №12.

Полный цикл CLI:

```sh
dotnet run --project src/TelegramChatNavigator.Cli -- save-state examples/demo --text маршрут --kind Link --out "$HOME/Documents/TelegramNavigatorCheck/demo-cli.tgnav.json"
dotnet run --project src/TelegramChatNavigator.Cli -- search "$HOME/Documents/TelegramNavigatorCheck/demo-cli.tgnav.json"
dotnet run --project src/TelegramChatNavigator.Cli -- export "$HOME/Documents/TelegramNavigatorCheck/demo-cli.tgnav.json" --out "$HOME/Documents/TelegramNavigatorCheck/demo-cli.csv"
```

Сохранение сообщает путь, повторный поиск возвращает два сообщения, CSV содержит ID 4 и 12.

Для собственного чата сначала задайте **свой настоящий путь**. В следующей строке MyChatExport — пример,
его нужно заменить фактической папкой с result.json:

```sh
CHAT_DIR="$HOME/Documents/TelegramNavigatorCheck/MyChatExport"
dotnet run --project src/TelegramChatNavigator.Cli -- inspect "$CHAT_DIR"
dotnet run --project src/TelegramChatNavigator.Cli -- search "$CHAT_DIR" --text "встреча" --limit 10
```

Подстроку `встреча` замените известным словом из вашего экспорта. Кавычки сохраняйте для путей с пробелами.

```text

Фото / видео / аудио / файл:
Сохранение и восстановление выбранного сообщения:
CSV:
Ошибки и отмена:
Собственный экспорт:
CLI:
Обнаруженные проблемы: действие → ожидалось → получилось.
```

Готовность к показу означает, что вы лично прошли основной сценарий, можете повторить его
без подсказки и объяснить результат. Автоматические тесты и ваша ручная проверка дополняют друг друга.
