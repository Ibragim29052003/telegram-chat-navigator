# Соответствие требованиям

Тема №20: **«Навигатор по экспортированному чату из Telegram»**.
Инструмент предназначен для локального просмотра заранее сохранённой переписки.
Ниже приведено описание реализации своими словами. Исходный файл преподавателя и чужие чаты в репозиторий не включены.

Обозначения: **О** — обязательное требование, **У** — требование при уместности/возможности,
**Р** — рекомендация. Путь Core означает `src/TelegramChatNavigator.Core`, Desktop — `src/TelegramChatNavigator.Desktop`,
Cli — `src/TelegramChatNavigator.Cli`.

## Функции пункта №20

| Требование | Статус и реализация | Файл | Как показать |
|---|---|---|---|
| О: папка экспорта из CLI или UI | Папка или файл в CLI, `--open` в GUI, системный выбор папки | `Core/ImportSupport.cs`, `Desktop/DesktopServices.cs`, `Cli/Program.cs` | Открыть examples/demo; затем examples/html-demo |
| О: переписка примерно в стиле Telegram | Лента с авторами, временем и выбором; полный текст справа; ответы | `Desktop/MainWindow.axaml`, `Desktop/ViewModels/MainViewModel.cs` | Выбрать №3, №10, длинный №13 |
| О: поиск | Подстрока без учёта регистра по тексту и связанным данным; совместные фильтры | `Core/Models.cs` → ChatSearch | `маршрут` → 4 сообщения; Link → 2 |
| О: быстрый переход по дню/месяцу | Бинарный поиск по отсортированным датам | `Core/Models.cs` → FindDate; ViewModel → JumpCore | 2026-10-01 или 2026-10 → №11 |
| О: навигация по фото, видео, файлам, аудио, ссылкам, опросам | Категории комбинируются с поиском/автором/периодом; страницы по 50 записей | `Core/Models.cs` → MessageKind; оба импортера; XAML | Переключить категории и применить поиск |
| О: участники диалога | Список всех авторов, присутствующих в экспорте, количество сообщений, фильтр по автору | `Core/Models.cs` → Participants | Выбрать Бориса и нажать «Найти» |
| О: предпросмотр медиа | Фото внутри Avalonia; видео/аудио/документы через Quick Look macOS | ViewModel → UpdatePreview; `Desktop/DesktopServices.cs` | №3: изображение; №7/8: «Предпросмотр macOS» |
| О: переход по гиперссылкам | Сохраняются обычные и скрытые адреса; открытие по нажатию | `Core/TelegramJsonImporter.cs`, `Core/TelegramHtmlImporter.cs`, `Desktop/DesktopServices.cs` | №4 → выбрать ссылку → открыть в браузере |
| Примеры и схема экспортной папки | Свои компактные демоданные с медиа и HTML; реальный маленький пример преподавателя использован только локально | `examples`, `docs/FORMATS.md` | Открыть готовые примеры без аккаунта |

Экспорт не содержит полного состава молчащих участников группы: приложение показывает авторов сообщений.
Формулировка №20 не уточняет встроенный ли нужен видеоплеер. Здесь используется системный предпросмотр;
если преподаватель подразумевает воспроизведение именно внутри окна, этот способ нужно отдельно согласовать.

## Общие требования к каждой работе

| Требование | Обязательность и реализация | Файл | Как показать |

| C#, актуальная .NET 10 | О: net10.0, SDK 10, стабильные версии пакетов | `Directory.Build.props`, `global.json`, `Directory.Packages.props` | `dotnet --info`, `dotnet build` |
| Основная логика в отдельных классах | О: модели, импортеры, поиск, состояние отделены от окна | `Core/*.cs` | Показать Core без ссылок на Avalonia |
| Библиотека классов | Р: реализована и используется обеими оболочками | `Core/*.csproj`, ProjectReference GUI/CLI | Один поиск через окно и CLI |
| Повторное использование логики | О для библиотеки: нет GUI/платформенных зависимостей в Core | `Core/Models.cs`, `Core/StateStore.cs` | CLI вызывает ChatImporter и ChatSearch |
| Классы, свойства, коллекции | О при уместности: record-модели, IReadOnlyList, ObservableCollection, HashSet | `Core/Models.cs`, ViewModel, StateStore | Объяснить сообщение, список, фильтр |
| Интерфейсы | О при уместности: IChatImporter, IDesktopServices, ICommand, INotifyPropertyChanged | `Core/Models.cs`, `Desktop/IDesktopServices.cs`, `ObservableObject.cs` | JSON/HTML реализуют один контракт, диалоги подменяются в тесте |
| Наследование | О при уместности: EventArgs, ObservableObject, Exception | `Core/Session.cs`, `ObservableObject.cs`, `Core/Models.cs` | Объяснить данные события и общий механизм уведомлений |

## Дополнения по запросу студента

Mac Apple Silicon без Windows; C# Dev Kit не переустанавливается; изоляция от существующих проектов;
проверка NuGet, CI, автономный .app/ZIP, подробное руководство, объяснение кода и русские комментарии,
примеры без личных данных, обработка отмены/ошибок и атомарная запись.
Эти дополнения выполнены в пределах, указанных в `VERIFICATION.md`.
Они не означают, что преподаватель требует CLI Notebook, публичный Mac-релиз или второй проект внутри этого решения.
