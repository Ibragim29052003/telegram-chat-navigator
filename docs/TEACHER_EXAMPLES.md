Проверены все пять архивов из [публичной папки задания](https://disk.yandex.ru/d/UOX5Mk7Nf6tXZQ).
Контрольные суммы SHA-256 скачанных архивов совпали с метаданными Яндекс Диска.
Архивы распакованы локально; чужие сообщения, медиа и файлы состояния в репозиторий не включены.

Всего 9635 исходных сообщений; каждый архив проверен в двух форматах — 10 вариантов импорта.
После исправлений совпали ID всех сообщений, категории вложений, количество авторов и сообщений со ссылками,
ссылки на ответы, результаты опросов (общее число голосов и каждый вариант). Во всех примерах один автор-канал.
Для JSON весь непустой исходный текст сопоставлен с нормализованным текстом; в HTML отдельно проверено,
что непустые сообщения не исчезли, включая пересылки. Побайтовое равенство оформления JSON/HTML не обещается.

## Проверенные операции

Для каждого из десяти вариантов отдельными процессами Release CLI выполнены:

1. Импорт, сохранение состояния и его повторное чтение.
2. Сверка всех ID и календарных дат с исходным JSON, сортировка по дате и ID.
3. Поиск по тексту; фильтр дня с включёнными границами; автор; автор вместе с периодом.
4. Избранное, обратный порядок, сохранение и восстановление этих параметров.
5. CSV найденного избранного; строки и порядок независимо прочитаны csv-модулем Python.

## Проверка в настоящем окне Mac

В автономной сборке 1.1.1 на macOS 27.0 / Apple Silicon:

- «Библиотека шарписта»: открыта папка через системный диалог; 6657 сообщений, один автор.
- Проверено переключение страницы с 1–50 на 51–100.
- Категория «Фотографии»: 2926 сообщений; фото №58 показано в отдельном окне.
- MP4 из сообщения №656: Play запустил шкалу, файл штатно дошёл до конца (2,69 секунды).
- Голосовое OGG №6176: системный AVKit подготовил файл, Play запустил шкалу; пауза и точная перемотка на 10 секунд работают.
- №6176 добавлен в избранное; фильтр оставил одно сообщение.
- Затем через диалог открыт «Здесь был памятник»: 23 сообщения. Этот пример оставлен в окне для самостоятельной проверки.

Физический звук через динамики удалённо не прослушивался. Не каждый медиафайл просмотрен вручную;
для остальных вложений проверены наличие и классификация. Поддержка произвольных кодеков и других версий ОС не гарантируется.

## Исправления, обнаруженные на этих примерах

- HTML: автор пересланного сообщения больше не подменяет автора чата; текст внутри пересылки читается.
- HTML: служебный суффикс `via @bot` не создаёт нового участника.
- HTML: ссылка со значком внутри опроса не превращается в несуществующее файловое вложение.
- JSON: `@username`, ссылки без схемы в сущностях `link` и URL-кнопки дают веб-ссылки, как в HTML.
- На эти случаи добавлены собственные компактные регрессионные данные; локально прошли все **59 тестов**.

Тот же набор из 59 тестов прошёл на каждой из трёх ОС в [CI коммита c1a5a19](https://github.com/Ibragim29052003/telegram-chat-navigator/actions/runs/42235738913).
Реальные архивы проверены локально; в CI используются собственные тестовые данные.

## Как повторить самому

Распакуйте нужный .7z, нажмите «Открыть экспорт» и выберите внутреннюю папку с result.json/messages.html.
При наличии обоих форматов окно предпочитает JSON. Явно проверить HTML можно из терминала:

```sh
dotnet run --project src/TelegramChatNavigator.Cli -- inspect "/путь/к/папке/messages.html"
dotnet run --project src/TelegramChatNavigator.Desktop -- --open "/путь/к/папке/messages.html"
```

Для первого показа удобен маленький пример на 23 сообщения; для воспроизведения настоящего видео/аудио —
«Библиотека шарписта». В ней можно искать `IMG_5402.MP4` и `audio_1@19-08-2025`. Сначала нажмите «Сброс»,
чтобы прежние ограничения поиска не скрыли нужное сообщение.
